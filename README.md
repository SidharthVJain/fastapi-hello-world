# Contributing Guidelines

Follow the steps below to submit your solution for this task.

---

## 1. Fork the Repository

Click the **Fork** button at the top-right of the repository, or use the link below:

https://github.com/mulearngectcr/fastapi-hello-world

This will create a copy of the repository under your GitHub account.

---

## 2. Clone Your Fork

Replace `<your-username>` with your GitHub username.

```bash
git clone https://github.com/<your-username>/fastapi-hello-world.git
cd fastapi-hello-world
```

---

## 3. Create a Folder with Your Name

Inside the repository, create a folder using your name and place your solution files inside it.

Example:

```text
fastapi-hello-world/
├── john-doe/
│   ├── main.py
│   ├── requirements.txt
│   ├── .gitignore
│   └── README.md
```

You may also include:

* Screenshots of your application
* Additional notes about your implementation
* Solutions to the bonus challenges

---

## 4. Commit Your Changes

```bash
git add .
git commit -m "Add submission - John Doe"
```

Replace `John Doe` with your name.

---

## 5. Push to Your Fork

```bash
git push origin main
```

If you are working on a separate branch, push that branch instead.

Example:

```bash
git push origin my-submission
```

---

## 6. Create a Pull Request

1. Open your fork on GitHub.
2. Click **Contribute → Open Pull Request**.
3. Submit the pull request to the original repository.

---

## Pull Request Title Format

Use the following format:

```text
Submission - Your Name
```

Example:

```text
Submission - John Doe
```
